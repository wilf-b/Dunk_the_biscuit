# Evaluating the Washburn Equation for Biscuit Dunking Using Machine Learning Techniques

This Report and code submission features three analysis notebooks and accompyniying report. 

The investigation I carried out was focused on discerning the points at which the Washburn Model failed and how well Linear Regression can be used to reconstruct these trajectories. 

When running the code they must be run in the order of 
- classification.ipynb
- microscopy.ipynb
- time_resolved.ipynb

this is owing to the fact that classification generates an aditional .csv file containing classification labels for the microscopy data
